## P2

### 2. 读文件和搜索工具

agent 现在读文件、找文件、搜代码都要用 `run_command` 跑 `cat`、`find`、`rg`：结果是一段纯文本，审批规则只能按命令写，也离不开命令执行。改成专门的只读工具。

- ollupi（`tools/workspace`，随 `workspace` 一起开关）
  - `read_file`：路径（相对项目根或绝对路径），可选起始行和行数；返回带行号的文本，单行过长截断；二进制文件不读，只返回类型和大小
  - `glob`：如 `**/*.go`，可限定目录；按修改时间从新到旧
  - `grep`：正则，可限定目录和文件名模式、忽略大小写；可只返回文件列表，或返回命中行及上下文
  - `glob`、`grep` 跳过 `.git`、遵守 `.gitignore`、跳过二进制文件；结果超长时截断，可用 `read_tool_output` 读回
  - 读取规则与沙箱一致：沙箱禁止读的路径（凭据文件、agent 数据目录、`config.yaml`）一律不读，`glob`、`grep` 遍历时跳过，并在结果里说明跳过了多少；沙箱关闭（完全访问）时同样生效，要读只能用 `run_command` 走提权审批
  - 标为只读工具：不需要审批，可以并行执行；权限规则按路径匹配，如 `read_file(src/**)`、deny `read_file(**/.env)`
  - 工具说明里写明读文件、找文件、搜内容优先用这三个工具，不用 `cat`、`find`、`grep`
- desktop
  - 重新生成协议类型；假模型加上三个工具的触发，重录会话记录
  - 时间线：`read_file` 显示路径和行范围，可展开看内容；`glob` 显示模式和文件数，可展开列表；`grep` 显示模式、范围和命中数，可按文件展开命中行
  - 连续的读取和搜索合成一行（"读了 3 个文件，搜索 2 次"），可展开逐个查看
  - 结果里的路径可点，在"文件"面板中打开

- desktop
  - 发布流程加签名和公证，用户首次打开不再被拦下

### 5. 远程访问

网关只给本机界面用。

- ollupi
  - 网关支持监听非本机地址，要求 token 认证和 TLS
  - 多个客户端同时连接时，审批和回答只处理第一个
- desktop
  - 设置里开启远程访问，显示地址和配对码
  - 移动端客户端另立项目
