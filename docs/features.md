# Ollupi 功能清单

覆盖 ollupi（Go 引擎库）和 ollupi-desktop（macOS 桌面端 + sidecar 后端）。标注：〔引擎〕ollupi 提供，〔桌面〕desktop 提供。

## 1. 执行与调度〔引擎〕

- 共享执行池
  - 所有会话、子代理、定时任务的 turn 进同一个队列
  - 槽位并发（默认 32），等审批 / 等回答 / 等子代理时让出槽位
  - 按模型连接限并发（默认每连接 4 个），工具执行不占名额
  - 优先级：普通会话先于子代理，同类先到先走
- 持久化与恢复
  - 状态全部存 SQLite，每一步先落库再执行
  - 进程重启后队列和进行中的 turn 接着跑
  - 工具调用区分 `pending` / `inProgress`，重启后知道能否重做
- 出错即暴露：读写库失败、权限数据不可读时立刻结束 turn 并通知界面

## 2. 会话（Thread / Turn）

- 会话管理〔引擎〕
  - 新建、列表、分页读取、恢复会话
  - 会话归属工作区，或不属于任何工作区（general）
  - 标题：新建时由界面给出，或重命名；子代理会话取任务描述
  - 归档 / 恢复：归档后不收新消息，定时任务不发送；有进行中的轮次时拒绝
  - 删除：连同子代理会话、附件和定时任务
  - 状态与会话变化通知（运行中、等待处理、改名、归档、删除）
- 一轮对话〔引擎〕
  - 开始、插话（steer，代理立即看到）、中断
  - 排队：当前轮跑完再发下一条
  - 模型文本与思考过程流式输出
  - 附件：图片（PNG / JPEG / GIF / WebP）和文本文件，每条最多 10 个，存在数据目录；不支持图片的模型拒绝而不丢弃
- 上下文管理〔引擎〕
  - 按模型的上下文 / 输出上限装入窗口
  - 超过阈值自动压缩，保留最近用户消息和工具产物
  - 工具输出过长时截断，可用 `read_tool_output` 分段读回
  - 系统提示词前缀保持稳定，利于服务商前缀缓存
- 会话界面〔桌面〕
  - 草稿页：选工作区和模型后输入第一条任务，标题取第一条消息的开头
  - 侧边栏：重命名（双击或点按钮）、归档、删除；已归档会话列表，可恢复或删除
  - 标题栏：点标题重命名；已归档的会话显示提示和恢复按钮
  - 时间线：消息、附件、思考（含耗时）、工具调用、压缩 / 记忆加载提示，加载更早消息
  - 输入框：发送、插话（Enter）、排队（Alt+Enter）、停止当前轮
  - 附件：粘贴、拖入或选择图片和文件，发送前预览；时间线里点开看大图或文本
  - 模型选择器（不可用模型会标出）
  - Markdown 渲染：代码高亮（shiki）、复制、Mermaid 图、脚注
  - 每轮用量：输入 / 缓存 / 写入缓存 / 输出 token
  - 标注由哪个定时任务发送的消息
  - 导出：Markdown，或含全部条目的 JSON，保存到自选位置
  - 自动滚到底 / 回到最新

## 3. 会话侧边面板〔桌面〕

- 浏览器：每个会话一个标签页，代理和用户共用；地址栏、前进、后退、刷新，用户可随时接手
- 文件：浏览工作区文件，预览文本（大文件只显示开头），用默认应用打开
- 改动：工作区相对上次 git 提交的改动列表（修改 / 新增 / 删除 / 未跟踪）和逐文件 diff
  - 暂存 / 取消暂存（单个或全部），标出部分暂存
  - 丢弃改动（先确认）：回到上次提交的样子；没有提交过的文件移到废纸篓
  - 填写提交信息，提交已暂存的文件（⌘Enter）
- 终端：每个工作区一个登录 shell，在工作区目录打开；用户自己的 shell，不经过代理和沙箱；关闭面板后继续运行，可新开
- 任务：代理当前的计划与进度（已完成 n/m）
- 上下文：系统提示词 / 工具定义 / 消息 / 记忆占比，窗口使用率，自动压缩点，最近调用的缓存命中，每次模型调用列表
- 会话权限：会话级审批策略和规则

## 4. 搜索

- 〔引擎〕`search`：一次查询，按类别返回会话（标题）、消息（用户消息和回复正文，带片段）、定时任务、记忆；多个词都要命中，可限定工作区
- 〔桌面〕
  - 侧边栏"搜索"（⌘K），分组展示结果并标出命中的词，可限定工作区
  - 点消息结果打开会话并定位到那条消息
  - 记忆页的搜索框

## 5. 子代理

- 〔引擎〕`Agent` 工具派生子代理，子代理是普通会话和 turn，结果作为父调用的结果返回
- 〔桌面〕时间线中显示子代理状态，可打开子代理会话、返回父会话；子代理会话只读，经父会话沟通

## 6. 审批与提问

- 审批〔引擎〕
  - 工具调用请求审批，决定：允许一次 / 在此会话中允许 / 拒绝
  - 总是允许：把规则写入工作区、会话或上级会话
  - 审批前冻结目录、命令和环境变量，执行时校验仍与批准内容一致
- 结构化提问〔引擎〕：`request_user_input`，回答成为工具结果
- 界面〔桌面〕
  - 审批卡片：显示命令或参数、是否在沙箱外运行及后果；文件修改显示冻结的 diff，网页读取显示 URL
  - 提问卡片：选项或自填回答，多题进度
  - 侧边栏标出"等待你处理"的会话

## 7. 权限与安全〔引擎〕

- 审批策略：严格（untrusted）/ 适中（on-request）/ 宽松（never）
- 规则：allow / ask / deny，如 `run_command(git:*)`
  - 代理默认、工作区、会话三层叠加，下层去不掉上层的 deny
  - 命令按程序名和参数结构化匹配，拆开 `sh -c`、`env`、`xargs`、`sudo` 等包装
  - 看不清的命令（变量、`$(...)`）不自动放行
- macOS Seatbelt 沙箱
  - 模式：只读 / 工作区可写 / 完全访问
  - 凭据文件不可读，缓存只读，`.git` hooks / config 不可写
  - 网络走代理，只放行允许的域名，拦截解析到内网的地址
  - 命令结束时清理派生的后台进程，报告沙箱拒绝原因
  - 跑出沙箱算提权，必须单独批准
- 双向脱敏
  - 识别手机号、邮箱、身份证、银行卡、IP、MAC、JWT、密钥
  - 发给模型前换成 HMAC 占位符，回答在记录和交给工具前还原
  - 可随时开关〔桌面：设置 → 通用〕

## 8. 工作区

- 〔引擎〕添加、重命名、归档；工作区级权限
- 〔桌面〕
  - 侧边栏按工作区分组会话，展开更多 / 收起
  - 在 Finder 中打开文件夹、在工作区中新建会话
  - 工作区设置：名称、权限
  - 已归档工作区列表与恢复

## 9. 工具与能力

- 内置工具〔引擎〕
  - `Agent`、`update_plan`、`request_user_input`、`read_tool_output`、`memory_search`
  - 技能：`list_skills`、`activate_skill`、`read_skill_resource`
  - 定时任务：`create_` / `pause_` / `delete_` / `list_scheduled_jobs`
  - `run_command`：沙箱内执行命令，可申请提权
  - `edit_file`、`write_file`：只写沙箱允许的目录；审批的是冻结的 diff，执行前确认文件未被改过；规则可按路径匹配
  - `web_fetch`：读取公网页面，HTML 转成类 Markdown 正文；只连公网地址，同域跳转跟随、跨域只返回新地址；按域名审批
  - 工具太多放不下时延迟加载，`load_tools` 按需载入
- MCP〔引擎〕
  - stdio 和 Streamable HTTP 两种传输，工具名 `<服务器>__<工具>`
  - 告诉 MCP 服务器是哪个会话在调用
- 浏览器工具〔桌面 sidecar〕：`navigate`、`snapshot`、`click`、`type`、`press_key`、`scroll`、`back`，操作的是会话自己的内置浏览器标签页
- 能力页〔桌面〕
  - 技能：开启 / 关闭、选择或更换技能文件夹、新建、编辑 SKILL.md、导入文件夹、删除（移到废纸篓），保存时校验并重启后端
  - MCP：添加 / 编辑 / 删除服务器，命令 + 参数 + 环境变量或 URL + Headers，`${NAME}` 引用环境变量中的密钥，显示连接状态和工具数
  - 工具：列出全部工具及只读 / 破坏性 / 外部标记

## 10. 定时任务

- 〔引擎〕5 字段 cron，按本地时区；到点向所属会话发一条消息，照常排队；暂停 / 恢复 / 删除；变更通知
- 〔桌面〕
  - 按工作区筛选任务列表，显示下次运行、上次发送、暂停 / 工作区或会话已归档 / 子代理不可发送等状态
  - 新建任务：选工作区和会话、名称、重复（每小时 / 每天 / 工作日 / 每周 / 每月）、时间、消息
  - 暂停、恢复、删除

## 11. 记忆

- 〔引擎〕
  - 后台从已结束的 turn 提炼记忆，与已有记忆合并（新建 / 更新 / 废弃）
  - 类型：偏好、决定、流程、事实
  - 范围：全局、无工作区（general）、各工作区
  - 会话开始时载入快照，压缩后再刷新；其余由 `memory_search` 搜索
  - 用户编辑或遗忘过的条目不被自动覆盖
  - 失败重试、跳过记录与状态查询
- 〔桌面〕
  - 按范围浏览、搜索记忆，编辑、遗忘、移到全局 / 移回
  - 状态：有效条数、待学习轮数、失败原因与重试时间、跳过记录
  - 设置：是否从会话学习、提取用的模型、是否在会话中使用

## 12. 模型〔桌面 + 引擎〕

- 三种 API：OpenAI 兼容、Anthropic、Gemini；模型以 `提供方/名称` 选择
  - Anthropic / Gemini 用原生接口：思考内容和签名原样回放，Anthropic 自动缓存断点、Gemini 隐式缓存
- 添加 / 编辑 / 删除提供方：API 类型、名称、Base URL、API 密钥
- 按 API 类型自动拉取模型列表（含能拿到的上下文上限），筛选、批量勾选
- 每个模型：上下文 / 输出上限、并发调用数、思考开关、是否支持图片
- 设默认模型、标出记忆所用模型
- 保存时由后端校验，再重启后端

## 13. 设置与外观〔桌面〕

- 通用：后端状态、数据文件夹（`~/.ollupi`）、打开 `config.yaml`、脱敏开关
- 通知：需要审批、需要回答、一轮完成、一轮失败分别开关；只在应用不在前台时显示，点击打开对应会话；Dock 角标显示等你处理的会话数
- 语言：跟随系统 / English / 简体中文
- 外观：跟随系统 / 浅色 / 深色；配色：梅子、宣纸、雾蓝、靛紫、古铜、黛蓝
- 检测 `config.yaml` 与后端实际使用的配置不一致

## 14. 后端托管〔桌面〕

- 启动、监督、重启 sidecar 后端（`ollupid`），握手后连接
- 启动失败时显示原因（超时、无法启动、意外退出）和后端日志
- 连接状态：已连接 / 启动中 / 已停止 / 重新连接
- 协议版本不一致时提示

## 15. 协议〔引擎〕

- WebSocket 上的 JSON-RPC 2.0，方法名对齐 Codex app-server
- 一张表同时分发请求并生成 `protocol.schema.json`，界面类型由它生成
- 用假模型跑完整会话，按契约校验每条消息

## 16. 安装与更新〔桌面〕

- macOS 12+，arm64 / x64 两种 DMG
- 从 GitHub Releases 自动检查更新，下载并安装，立即重启或退出时安装
- 显示更新内容，失败可重试；应用不在可替换位置时提示移到"应用程序"
