[ollupi](https://github.com/0xfakeSpike/ollupi) 的 macOS 桌面端。所有会话、子代理和定时任务共享一个执行池，可以同时开很多个会话；等你审批或回答的会话不占并发名额，状态存在本机，重启后接着跑。

## 安装

需要 macOS 12 或更新。从 [Releases](https://github.com/0xfakeSpike/ollupi-desktop/releases/latest) 下载：Apple 芯片选 `arm64.dmg`，Intel 选 `x64.dmg`，打开后把 Ollupi 拖进"应用程序"。

应用未经 Apple 公证，第一次打开会被拦下：到 **系统设置 → 隐私与安全性** 底部点"仍要打开"，或者执行：

```bash
xattr -dr com.apple.quarantine /Applications/Ollupi.app
```

之后不用再手动下载：有新版本时侧边栏会提示，点 **下载并安装**，下载完点 **立即重启**（或者下次退出时自动装上）。也可以在 **设置 → 通用 → 更新** 里手动检查。

## 使用

1. **配置模型**：**设置 → 模型 → 添加提供方**，选 API 类型（OpenAI 兼容、Anthropic 或 Gemini），填名称、Base URL 和 API 密钥，勾选模型并填上下文和输出上限，点 **保存并重启**。手写 `config.yaml` 时每个提供方都要写 `type`（`openai`、`anthropic` 或 `gemini`）。
2. **开始会话**：**添加工作区** 选一个项目文件夹，再点 **新会话**，选好工作区和模型后输入任务，可以粘贴或拖入图片和文件。一轮还在跑时可以 **插话** 或 **排队**。会话可以在侧边栏重命名、归档和删除，⌘K 搜索会话、消息、定时任务和记忆。
3. **审批**：agent 要做需要确认的操作时，选 **允许一次**、**在此会话中允许** 或 **拒绝**；同类操作不想再被问，点 **总是允许**。审批策略分 **严格**、**适中**、**宽松**，在 **工作区设置 → 权限** 或会话右上角的 **会话权限** 里改。命令默认在 macOS 沙箱里跑。

会话右上角还能打开 **浏览器**（agent 和你共用的内置浏览器，每个会话一个标签页）、**文件**、**改动**（工作区里未提交的 git 改动，可以暂存、丢弃和提交）、**终端**（你自己的 shell，在工作区目录打开）和 **任务**（agent 当前的计划），也可以把会话导出成 Markdown 或 JSON。应用不在前台时，需要审批、需要回答或一轮结束会发系统通知。

此外还有 **定时任务**（到点向会话发一条消息）、**记忆**（从会话中学习，在会话中使用），以及 **能力** 里的技能、MCP 服务器和工具列表。

配置和数据都在 `~/.ollupi`，配置文件是 `~/.ollupi/config.yaml`，可在 **设置 → 通用** 里打开。后端起不来时，界面会显示原因和后端日志。
